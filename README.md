# Rakhi Bloom

AI CINEMATIC VISUAL SYSTEM

Forever Rakhi Bond ❤️

CRITICAL REQUIREMENT

This website MUST use actual AI-generated cinematic visuals throughout the experience.

Do NOT create a website using:

generic stock photos

random internet images

generic SVG people

flat illustrations

emoji characters

CSS-only character drawings

placeholder rectangles

unrelated images

The visual storytelling is the CORE of this website.

The website should feel like an original animated cinematic short film created specifically for this project.

01 — CREATE THE CHARACTERS FIRST

Before generating any scene, establish two primary recurring characters:

BROTHER

Create one consistent Indian brother character.

Age progression:

Childhood: approximately 7–9 years old

Teenage: approximately 15–17

Young adult: approximately 22–26

Future: older adult version

Character identity must remain recognizable across every age.

Maintain:

same facial identity

same eye shape

same hairstyle language

same skin tone

same body proportions

same overall personality

same visual design

SISTER

Create one consistent Indian sister character.

Age progression:

Childhood: approximately 6–8 years old

Teenage: approximately 14–16

Young adult: approximately 21–25

Future: older adult version

Maintain the same:

facial identity

hairstyle language

skin tone

body proportions

visual personality

The sister must clearly feel like the same character throughout the entire story.

02 — MASTER ART DIRECTION

Every generated image must follow ONE unified visual direction.

Style:

cinematic premium 3D animated illustration

Visual characteristics:

emotionally expressive characters

sophisticated cinematic lighting

realistic environmental depth

soft skin rendering

detailed Indian environments

subtle film grain

volumetric sunlight

realistic fabric

shallow depth of field

atmospheric perspective

warm highlights

elegant color grading

premium animated-film composition

The result should feel like:

an expensive animated short film + luxury editorial photography + Indian family nostalgia.

Do NOT make it look childish.

Do NOT make it look like a generic cartoon.

Do NOT imitate any specific studio or copyrighted animation franchise.

Create an original visual identity.

03 — CONSISTENCY SYSTEM

Every scene MUST reuse the established character references.

Do NOT independently redesign the characters for each image.

Create a consistent visual bible:

BROTHER_CHARACTER_REFERENCE
SISTER_CHARACTER_REFERENCE
CHILDHOOD_ENVIRONMENT_REFERENCE
HOME_INTERIOR_REFERENCE
COLOR_PALETTE_REFERENCE
LIGHTING_REFERENCE
COSTUME_REFERENCE


Every generated scene should inherit these references.

04 — IMAGE COMPOSITION

Generate artwork specifically for website animation.

Do NOT generate only centered portraits.

Use cinematic compositions with empty areas for typography.

Examples:

Character on left → empty space on right for text.

Characters at bottom → open sky above.

Room foreground → empty wall area for chapter title.

Use:

wide cinematic compositions

16:9 hero scenes

vertical-safe composition for mobile

foreground / middle-ground / background separation

05 — GENERATE LAYERABLE VISUALS

Whenever possible, generate scenes that can be separated into:

BACKGROUND

Environment.

MIDGROUND

Furniture / trees / architecture.

CHARACTER LAYER

Brother and sister.

FOREGROUND

Flowers / curtains / objects / leaves.

ATMOSPHERE

Dust / particles / sunlight / petals.

This allows JavaScript/CSS parallax animation.

THE GOLDEN RULE

If an AI-generated image feels like a generic AI image, reject it and regenerate it.

If the brother looks different between scenes, reject it and regenerate it.

If the sister looks different between scenes, reject it and regenerate it.

If the lighting/art direction changes dramatically, reject it and regenerate it.

The entire website must look as if one animation studio created one continuous film about the same brother and sister.
